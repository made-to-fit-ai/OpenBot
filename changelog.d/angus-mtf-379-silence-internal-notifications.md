### Fixed

- An agent that finishes work that another agent asked for no longer notifies you on the desktop or
  the phone, and plays no sound. Its result goes to the agent that asked, and you get one
  notification when that agent answers you. Before, a request to six teammates gave seven
  notifications, most of them "Finished working.". A question, an approval, an error and your own
  messages to an agent still notify.
